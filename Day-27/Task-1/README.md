# Personal Profile Page

This project is a simple personal profile webpage created using HTML, Tailwind CSS, and custom CSS. It presents my profile information, education, experience, projects, technical skills, and contact details in a clean single-page layout.

## How I Made It

First, I created the basic HTML structure in `index.html` using standard tags like `header`, `nav`, `main`, `section`, and `footer`.

Then, I added Tailwind CSS through the CDN link in the HTML file. Tailwind utility classes were used for layout, spacing, colors, text styling, responsiveness, and alignment.

After that, I divided the page into different sections:

- Header section with my name, profile image, role, contact details, and important links.
- Navigation bar with links to each section of the page.
- About section to introduce myself.
- Education section to list my academic details.
- Experience section to show internships, work experience, and hackathon achievements.
- Projects section to display important projects with images and descriptions.
- Skills section to list programming languages, tools, frameworks, databases, and cloud technologies.
- Contact section with email and phone number.

I also created a separate `styles.css` file for reusable custom styles. In this file, I added styles for cards, section titles, project boxes, project images, smooth scrolling, and paragraph spacing.

Finally, I connected `styles.css` to `index.html` using a `<link>` tag and checked the page in the browser to make sure all sections were displayed properly.

## Technologies Used

- HTML
- Tailwind CSS
- CSS

## Files

- `index.html` - Contains the main webpage structure and content.
- `styles.css` - Contains additional custom styling.
- `README.md` - Explains the project and how it was made.

## How to Run

Open the `index.html` file in any web browser.
