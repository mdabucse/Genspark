# GenSpark Training Learning Summary

This document summarizes the main topics and skills I learned during the GenSpark training.

## 1. Programming Fundamentals
- Learned the basics of programming concepts such as variables, data types, loops, conditions, and functions.
- Understood how to write clean and structured code.
- Practiced problem-solving using simple coding exercises and DSA problems.

## 2. C# and Object-Oriented Programming
- Learned the fundamentals of C# programming.
- Understood object-oriented programming concepts like:
  - Classes and objects
  - Inheritance
  - Polymorphism
  - Encapsulation
  - Abstraction
- Learned advanced OOP topics and how to design better software.

## 3. Exception Handling
- Learned how to handle runtime errors using try-catch blocks.
- Understood the importance of writing robust and safe code.

## 4. SQL and Database Concepts
- Learned SQL basics such as SELECT, INSERT, UPDATE, and DELETE.
- Practiced using joins, stored procedures, and database queries.
- Understood how databases are connected to applications.

## 5. Entity Framework Core
- Learned how to use Entity Framework Core for database operations.
- Understood concepts like DbContext, migrations, and models.
- Learned how ORM tools simplify database interaction.

## 6. ASP.NET Core and Web API Development
- Learned how to build web applications and APIs using ASP.NET Core.
- Understood routing, controllers, models, and services.
- Built simple APIs and practiced API development.

## 7. DTOs and API Design
- Learned the use of Data Transfer Objects (DTOs) to structure API data.
- Understood the importance of clean API design and separation of concerns.

## 8. Authentication and Authorization
- Learned about JWT authentication.
- Understood how to secure APIs and manage user access.
- Explored authentication concepts using Auth0.

## 9. Asynchronous Programming
- Learned how asynchronous programming works in C#.
- Understood the use of async and await for better performance.

## 10. Testing
- Learned the basics of unit testing.
- Understood the importance of writing testable and reliable code.

## 11. Advanced Concepts
- Learned about delegates and extensions in C#.
- Explored event-based and modular programming patterns.
- Understood publisher-subscriber concepts and how services communicate.

## 12. Frontend Basics
- Learned basic frontend development concepts.
- Understood how frontend and backend work together in a full-stack application.

## 13. Project Experience
- Built multiple mini-projects and practice applications during the training, including:
  - Notification App
  - Banking API
  - Todo API
  - Book Management System
  - CRUD-based applications
  - Excel export application

## 14. Overall Growth
- Improved my coding skills and problem-solving ability.
- Learned how to build real-world applications step by step.
- Gained confidence in backend development, databases, APIs, and software design.

## Conclusion
The GenSpark training helped me gain a strong foundation in modern software development, especially in C#, ASP.NET Core, databases, APIs, and application architecture.
